## Fitur Utama
1. **Wallet Connection:** Integrasi MetaMask untuk mengambil alamat dan saldo user secara real-time.
2. **Backend API:** Menyediakan data transaksi dummy melalui Node.js & Express.
3. **Smart Contract Integration:** Menampilkan status aktif dari simulasi Smart Contract.
4. **Responsive UI:** Menggunakan CSS Grid untuk tampilan yang rapi di berbagai perangkat.

## Cara Menjalankan Aplikasi Lokal

### 1. Persiapan Backend
Buka terminal, masuk ke folder backend, dan jalankan server:
```bash
cd backend
node server.js
Server akan berjalan di http://localhost:5000.

### 2. Persiapan Frontend
Buka terminal baru, masuk ke folder frontend, dan jalankan React:
cd frontend
npm start
Aplikasi akan terbuka di http://localhost:3000.
